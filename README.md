# スカイライン・テクノロジーズ 企業サイト

架空のソフトウェア開発会社「スカイライン・テクノロジーズ」の1ページWebサイトです。
本サイトの企業名・数値・実績などはすべてフィクションです。

## 概要

クラウド・AI・モバイル開発でDXを支援する、という設定の企業サイトです。
HTML・CSS・JavaScriptを `index.html` 1ファイルにまとめており、ビルドや外部ライブラリは不要です。

### 掲載セクション

- お知らせ欄(ナビゲーション直下)
- ヒーロー(キャッチコピー)
- 事業内容
- 導入実績
- 会社情報
- お知らせ一覧
- お問い合わせ(デモ用フォーム。実際には送信されません)

スマートフォンの画面幅にも対応しています。

## ブラウザで index.html を開く手順

1. このリポジトリをダウンロード(またはクローン)し、`company-site` フォルダを開きます。
2. エクスプローラーで `index.html` をダブルクリックします。
   既定のブラウザでサイトが表示されます。
3. 別のブラウザで開く場合は、`index.html` を右クリックして「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウへドラッグ&ドロップします。
